# Security Policy

## Supported versions

This project doesn't have a stable version line yet. Only the `main` branch
and the most recently published tag are supported; security fixes target the
latest release.

## Reporting a vulnerability

**Please don't open a public issue** for a vulnerability.

Use GitHub's private reporting flow instead:

1. Go to this repo's **Security** tab → **Report a vulnerability**.
2. Describe the issue: reproduction steps and impact, if known.

We'll acknowledge the report and work with you on a fix and a disclosure
timeline. There's no contractual response SLA — this project is maintained
by a single person.
